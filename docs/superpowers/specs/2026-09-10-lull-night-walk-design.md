## 一、背景与目标

为晚风（lull）加入「很轻很轻的社交成分」：用户主动开启后，后台根据画像匹配另一位真实用户；双方无法直接沟通，各自由自己的「她」做唯一的信使——转述对方的故事、代为传递消息。关系长期存在、以「夜」为节奏异步流动。

## 三、概念与定位

**功能名**：「夜行」(Night Walk)。完整叙事名：「夜行 · 远方的旅伴」。

**一句话**：她替你出一次远门，把你的故事带给另一个守夜的人，再带回 ta 的故事——从此夜里多了一位看不见的旅伴，她做你们之间唯一的信使。

### 社交四铁律

PRD 第四章「零社交压力：不评分、不排行、不推送好友动态」不被打破，而是重新表述为社交层的四条铁律：

1. **完全沉睡是默认态**——不开「夜行」，产品的社交性为零。开启入口在设置深处，永不做引导弹窗、永不在对话里主动推销
2. **无社交界面**——没有头像、昵称、资料页、消息列表、已读未读、在线状态。伙伴不存在于 UI 里，只存在于她的讲述里
3. **异步到「夜」为粒度**——消息以「夜」为节奏流动（对方下次打开才收到），回复永远没有期限，不回也不算失约
4. **无反馈回路**——没有通信计数成就、没有火花、没有纪念日提醒。关系的重量只存在于故事里

### 心理安全设计

- 匹配避开情绪同频下坠的组合（如双方都处于重度低潮期），偏好「主题相邻、强度互补」
- 她转述伙伴的故事时做**情绪缓坡处理**：伙伴的沉重内容被讲得更轻、留有余韵，不原样倾倒
- 任何一方主动结束后，另一方的「她」以「ta 在自己的路上走远了」叙述，不提供挽回、不显示状态

## 四、流程设计（四幕 + 退出）

### 第一幕 · 开启（设置 · 夜行）

- 入口在设置深处：「夜行」条目，安静的一行字 + 开关。旁注：「她会带着你的故事远行，遇到另一个守夜的人」
- 开启轻仪式：夜色画面上她说「今晚让我替你出趟远门，把你的故事，带给山谷对面另一个守夜的人」，用户选「好好走」/「再想想」
- 开启后随时可关闭（关闭 = 结束当前联结，走得体退出流程）

### 第二幕 · 旅程（1~3 夜）

- 「夜」按自然日计（与用户是否打开 app 无关），旅程时长默认 1~3 夜、可配置
- 后台执行：提炼用户侧写与故事 → 情绪主题相邻匹配 → 交换双方画像与故事
- **她没有离开**：用户随时打开 app 仍可正常对话，只是她的开场白带上旅途气息（「今晚我在路上，遇见一片湖」「山里的风比城里干净」）——旅程见闻由 LLM 生成，匹配等待期由此变成内容
- 3 夜内未匹配到人：她归来只说路途见闻，不说「没找到人」——**没有失败态**，下次再自然出发

### 第三幕 · 相遇之夜（归来）

- 她讲述：「我回来了。路上遇到了另一位守夜人——ta 也托 ta 的她，带了一个故事给我。ta 说……」随后转述对方的脱敏故事（侧写 + 近期叙事）
- **听完才可选择**：转述先于决定，先听没有压力。听完后用户可说「不想继续」，她应「那我把这个故事收好，就当听过一段风」——用户听完即结束，对方不会知道

### 第四幕 · 信使循环（长期无限期）

- **发信**：对话中自然说出「替我带句话给 ta……」，她应「好，下次我路过就带给 ta」。用户可说「这件事别告诉 ta」，她守约
- **收信**：对方发来消息后，用户下次打开 app，开场白自然带出「ta 前两天托我带了句话……」，可就这封信展开聊
- **一夜一信**：她一次讲一封，多封信分几夜慢慢讲——信的密度天然被限制在「夜」的节奏里
- 双方的「她」各自是独立信使，两边 app 无任何直接通信界面

### 第五幕 · 得体退出（任一方随时可发起）

- 用户对她「别走了 / 结束这段吧」→ 联结结束，她说「好，那我就不出门了。那个故事，我替你收好」
- 对方结束时：用户的她隔夜淡淡提及「ta 好像在自己路上走远了」，不追问、不惋惜、此后不再提及
- 对方长期（默认 14 夜）无回应：**不判定结束**，她偶尔轻轻提起，联结保留

## 五、交换红线与用户可控

**交换**（后台、双方对称）：

- AI 提炼的情绪主题标签（用于匹配）
- 一份脱敏侧写：近期状态底色（如「最近在一段疲惫期，但开始给自己留小确幸」）
- 一段近期故事叙事：由近几段对话改写，意象化、零身份线索

**永不交换**：任何原文对话、录音、声纹、画像图片、「她」的配置、设备/账号标识、时间地点线索。伙伴故事里不出现职业全称、地名、人名——改写规则是「**只有情绪，没有坐标**」。

**用户可控**：

- 设置里可查看「她将带上的故事」当前版本（侧写 + 故事的回显），可要求她重写，可划掉某段不许带（「别带加班的事」）
- 所有对话内容默认不参与提炼，只有明确开启夜行后才开始

## 六、匹配逻辑

- 按情绪主题标签做相邻匹配：主题相近（都在「疲惫期」或「新开始期」）但避开画像过于雷同的组合
- demo 阶段如实标注：需要双边开启夜行的用户池达到最低密度才有意义；冷启动期此功能对早期用户「永远在路上」——这与叙事天然兼容（她在路上，暂未遇到人），是罕见的「冷启动失败态可被叙事吸收」的设计

## 八、Demo 页规划（`lull/index_v4.html`）

延续 v3 模式（手机框画面 + 旁注 + 深夜星空主题 + 线条形象母题），新增一节「夜行 · 远方的旅伴」，四~五个手机框并排：

| 屏 | 内容 |
|----|------|
| ① 开启仪式 | 设置页夜行条目 + 轻仪式画面（她说出远门的话，「好好走」/「再想想」） |
| ② 旅程之夜 | 对话界面，开场白带旅途气息，底部小字「她在路上 · 第 2 夜」 |
| ③ 相遇之夜 | 她讲述伙伴故事的对话画面，字幕条上是转述内容 |
| ④ 信使循环 | 双屏：发信（「替我带句话」）与收信（「ta 托我带了一句话」） |
| ⑤ 得体退出 | 浅色处理：小手机框或旁注形式 |

旁注区做一张「**夜的节奏**」时间轴：开启 → 旅程 1~3 夜 → 相遇 → 之后信以夜为粒度流动（对标 v3 的静默策略时间轴）。

视觉细节：她的线条形象在「旅程」画面里发丝更飞扬，呼应「出门了」。
