> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付「一局」的产品文档 `gamelearn/PRD.md` 与可点通原型 `gamelearn/index.html`——用户说一句想学什么，产品演出一局真正能玩的游戏，玩完结算、发布到广场、被二创、进榜。

**Architecture:** 单文件 HTML，内联 CSS/JS，零依赖、零网络请求。文件内部分为 STATE / DATA / ROUTER / COMPONENTS / GAMES / SELFTESTS 六个带标记的区段。内置 `SELFTESTS` 注册表，`?selftest=1` 时运行全部断言并把结果写入 `document.title`，用 headless Edge 回读，实现无框架的自动化验收。

**Tech Stack:** 原生 HTML/CSS/JS（无构建、无 CDN、无外部字体与图片）；DOM + CSS transform 实现游戏，不用 Canvas（便于断言）；测试用 `Microsoft Edge --headless --dump-dom`。

**Spec:** `docs/superpowers/specs/2026-09-14-yiju-design.md`

## Global Constraints

- **单文件**：全部内容在 `gamelearn/index.html` 内联。无构建步骤、无 npm、无 `<script src>`、无 `<link rel="stylesheet">`。
- **零网络**：不得引用任何 CDN、外部字体、外部图片、图标字体。图标一律用 emoji 或内联 SVG。断网也能完整走通。
- **画布**：固定 390×844，桌面上居中并带设备外框；窗口小于画布时等比缩放。
- **语言**：全部文案中文。
- **不做**：后端、真实 AI 调用、账号、登录、推送、支付、真实分享 SDK。
- **匿名化红线**：站外邀请卡不得出现真实姓名、头像、账号 ID，只能用"一位五年级同学""一位吉他初学者"这类身份描述。
- **四条生成律**（spec 第五章，演出中必须体现）：
  1. 玩法先于知识——机制本身在没有知识时也成立
  2. 知识是操作——知识表现为手上的动作，不是"题干 + 四个选项"
  3. 失败改变游戏世界——**任何地方都不允许出现"答错啦，正确答案是…"这类弹窗**
  4. 一局 60–120 秒、有明确胜负、有"再来一局"
- **demo 规模**：目标 4 个（2 深做 `guitar`/`fraction` + 2 浅做 `english`/`fund`）；机制 6 个（`rhythm` 与 `collide` 真能玩，其余静态占位）；广场预置 16 个作品。
- **自检协议**：结果写入 `document.title`，通过为 `SELFTEST OK`，失败为 `SELFTEST FAIL: <用例名>`。失败时 title 可再带 `: <原因>` 后缀（便于定位），因此判定一律用**前缀匹配**——`SELFTEST OK` 取全等，失败只要求以 `SELFTEST FAIL: ` 开头。
- **测试命令**（下称"自检命令"，每个任务都用它）：

```bash
EDGE="/Applications/Microsoft Edge.app/Contents/MacOS/Microsoft Edge"
"$EDGE" --headless --disable-gpu --no-sandbox --virtual-time-budget=4000 \
  --dump-dom "file://$PWD/gamelearn/index.html?selftest=1" 2>/dev/null \
  | grep -o '<title>[^<]*'
```

两个参数和 grep 的写法都不能省，理由各一条：

- `--virtual-time-budget=4000` 必须留。自检在 `load` 之后 50ms 才启动（`setTimeout(runSelftests, 50)`），而 `--dump-dom` 在 load 完成时就抓 DOM。省掉这个参数会抓到尚未写入结果的标题——实测省掉后 **12 次里 6 次** 只打印裸的 `<title>一局`，带上后 **12/12** 稳定（4000 实测 12/12，8000 亦可用）。凭记忆手敲这条命令极易漏掉它，然后得到"一半概率像失败"的假象。
- grep **不带** `</title>`。断言失败的原因可以跨行（例如 `TypeError` 带栈），带闭合标签的写法是逐行匹配，跨行失败会**什么都匹配不到**——空输出会被误读成"没问题"。去掉闭合标签恰好也是上面「判定一律用前缀匹配」那条规则的实现方式：通过取全等 `SELFTEST OK`，失败只要求以 `SELFTEST FAIL: ` 开头。
- **空输出一律当作"要查"，绝不当"通过"。** 标题既不是 `SELFTEST OK` 也不是 `SELFTEST FAIL: ` 前缀时（例如裸的 `一局`，说明脚本在写标题之前就抛了）同样算失败。

> **执行期修正（2026-09-14，Task 1 评审后）** — Step 1 的代码片段是下面几处的**过时来源**，实现时以下列版本为准：
>
> 1. **等比缩放**：片段漏了 Global Constraints 里的「窗口小于画布时等比缩放」。补 `computeScale(w,h) = Math.min(1, w/390, h/844)`，套在 `#scaler` 包装层上（`transform-origin:center`），**不要改 `#phone` 自身的 390×844**——后续所有任务都在这个坐标系里测量。`body` 同时从 `min-height:100vh` 改为 `height:100vh; overflow:hidden`：用 `min-height` 时小窗口下 body 会被 844px 的子元素撑高，flex 居中变成相对文档，缩放后的手机有一部分跑到视口外。
> 2. **缩放容器命名为 `#scaler`，不叫 `#stage`**：游戏挂载点是**类** `.cg-stage`（Task 4 起）。浏览器会把带 id 的元素暴露成 `window` 全局，裸的 `stage` 自由变量会静默取到包装层而不报 ReferenceError；且 `getBoundingClientRect()` 返回**缩放后**的像素（headless 下 `scale≈0.559`），Task 5 要做坐标运算，取错元素会拿到 0.56× 的数。
> 3. **`runSelftests` 必须顺序 `await` 每个用例**（拆成可测内核 `runList`）：同步版会把异步用例的 rejection 吞掉，title 谎报 `SELFTEST OK`。**这是本项目的探针是唯一验证手段，必须诚实。**
> 4. **顺序屏障用例**：异步用例自身无法捕获「runner 没 await」——检测器与被检测的缺陷共用一条失败路径。故用一个**同步**屏障用例读计数器：异步用例末尾自增 `awaitedProbeMarks`，紧随其后的同步用例断言 `awaitedProbeMarks >= 1`。runner 若退回同步版，异步用例在 `await` 处挂起、屏障立即执行读到 0 并抛出，走普通 try/catch 路径把 title 置为 FAIL。
>
> 这四处已由 Task 1 的 fix round 落地并复审；后续任务的 brief 文本未受影响（全 plan 中无一处引用 `#stage`，已 grep 核对）。

function runRhythm(content, mount){
  const JUDGE = 0.82;                 // 判定线位置（0=顶 1=底）
  const WINDOW = 0.18;                // 判定窗口半径
  const FALL = 0.00022;               // 每毫秒下落比例，乘速度
  const GAP = 0.09;                   // 相邻方块的出发间距（错开，否则 24 个一起落）
  let hp = content.hp, combo = 0, maxCombo = 0, hits = 0, t0 = performance.now();
  let queue = content.blocks.map(b=>({ ...b, pos: -b.at * GAP, live:true }));
  let raf = null, last = 0, over = false;

  mount.innerHTML = `
    <div class="rhythm">
      <div class="hud">
        <span class="hp">${hp}</span>
        <span class="combo">0</span>
      </div>
      <div class="lanes">
        ${content.tracks.map((c,i)=>`
          <button class="track" data-track="${i}">
            <span class="tk-chord">${c.label}</span>
            <span class="tk-fing">${c.fingering}</span>
          </button>`).join('')}
        <div class="judge-line"></div>
        <div class="blocks"></div>
      </div>
    </div>`;

  const lanes = mount.querySelector('.blocks');
  const elHp = mount.querySelector('.hp');
  const elCombo = mount.querySelector('.combo');

  function paint(){
    lanes.innerHTML = queue.filter(b=>b.live)
      .map(b=>`<div class="block" data-track="${b.track}" data-live="1"
                    style="top:${(b.pos*100).toFixed(1)}%">${content.tracks[b.track].label}</div>`).join('');
  }

  function step(dt){
    if(over) return;
    const speed = 1 + Math.min(0.6, (performance.now() - t0) / 150000);
    queue.forEach(b=>{
      if(!b.live) return;
      b.pos += FALL * dt * speed;
      if(b.pos >= JUDGE + 0.06){                  // 漏掉
        b.live = false; combo = 0;
        hp--; reportAttempt({ point:b.point, ok:false, ms: dt });
        flash('miss');
      }
    });
    elHp.textContent = hp;
    elCombo.textContent = combo;
    paint();
    if(hp <= 0) return end('lose');
    if(hits >= content.blocks.length) return end('win');
  }

  function hit(trackIdx){
    if(over) return;
    const cand = queue.filter(b=>b.live && b.track === trackIdx && Math.abs(b.pos - JUDGE) < WINDOW);
    const target = cand.sort((a,b)=> Math.abs(a.pos-JUDGE) - Math.abs(b.pos-JUDGE))[0];
    if(target){
      target.live = false; hits++; combo++; maxCombo = Math.max(maxCombo, combo);
      reportAttempt({ point: target.point, ok:true, ms: Math.round(performance.now() - t0) });
      flash('hit');
    } else {
      combo = 0; hp--;
      reportAttempt({ point: content.tracks[trackIdx].label + '和弦指法', ok:false, ms: 0 });
      flash('miss');
    }
    elHp.textContent = hp;
    elCombo.textContent = combo;
    paint();
    if(hp <= 0) return end('lose');
  }

  function flash(kind){
    const el = mount.querySelector('.rhythm');
    el.classList.remove('fx-hit','fx-miss');
    void el.offsetWidth;
    el.classList.add('fx-' + kind);
  }

  function end(outcome){
    over = true;
    cancelAnimationFrame(raf);
    finishRun({ outcome, ms: Math.round(performance.now() - t0), maxCombo, hits, total: content.blocks.length });
    showResult(outcome, { maxCombo, hits, total: content.blocks.length });
  }

  mount.querySelectorAll('.track').forEach(t=>{
    t.addEventListener('click', ()=> hit(Number(t.dataset.track)));
  });

  function loop(now){
    const dt = last ? now - last : 16;
    last = now;
    step(dt);
    if(!over) raf = requestAnimationFrame(loop);
  }
  if(!SELFTEST_MODE){ raf = requestAnimationFrame(loop); }
  paint();

  return {
    destroy(){ over = true; cancelAnimationFrame(raf); },
    _step(dt){ step(dt); },
  };
}

function summarize(){
  const by = {};
  BUS.attempts.forEach(a=>{
    by[a.point] = by[a.point] || { ok:0, n:0 };
    by[a.point].n++; if(a.ok) by[a.point].ok++;
  });

    .sort((a,b)=> b.rate - a.rate);
  const strong = rows.filter(r=> r.rate >= 0.8);
  const weak = rows.filter(r=> r.rate < 0.8).sort((a,b)=> a.rate - b.rate);
  const strongTxt = strong.length ? strong.map(r=>r.point).join('、') : '还没有稳定的部分';

    ? `下一关把${weak[0].point}放慢一点，多给你几次机会`
    : '下一关提速，试试《完整来一遍》';
  return { strong: strongTxt, weak: weakTxt, next };
}

function runCollide(content, mount){
  let wave = 0, wallHp = content.wallHp, over = false, last = 0, raf = null;
  let zombies = [];

  mount.innerHTML = `
    <div class="collide">
      <div class="hud"><span class="wall">${wallHp}</span><span class="wave">第 1/8 波</span></div>
      <div class="field"><div class="wall-face"></div></div>
      <div class="turrets"></div>
    </div>`;

  const field = mount.querySelector('.field');
  const elWall = mount.querySelector('.wall');
  const elWave = mount.querySelector('.wave');
  const elTurrets = mount.querySelector('.turrets');

  function optionsFor(z){
    const opts = [z.answer, ...z.decoys];        // opts[0] 恒为正确答案
    const k = z.expr.replace(/\D/g, '').length % opts.length;
    const rot = opts.slice(k).concat(opts.slice(0, k));   // 确定性轮转打乱，便于自检
    return rot.map(label => ({ label, ok: label === z.answer }));
  }

  function spawnWave(){
    zombies = content.waves[wave].zombies.map(z=>({ ...z, pos:0, live:true, opts: optionsFor(z) }));
    elWave.textContent = `第 ${wave+1}/8 波`;
    paint();
  }

  function front(){ return zombies.filter(z=> z.live).sort((a,b)=> b.pos - a.pos)[0]; }

  function paint(){
    field.querySelectorAll('.zombie').forEach(e=> e.remove());
    zombies.filter(z=> z.live).forEach(z=>{
      field.insertAdjacentHTML('beforeend',
        `<div class="zombie" data-id="${z.id}" data-pos="${z.pos.toFixed(3)}"
              style="right:${(z.pos*72).toFixed(1)}%">
           <span class="zm-body">🧟</span><span class="zm-expr">${z.expr}</span>
         </div>`);
    });
    const f = front();
    elTurrets.innerHTML = f ? f.opts.map((o,i)=>
      `<button class="turret" data-ok="${o.ok ? 1 : 0}" data-i="${i}">${o.label}</button>`).join('') : '';
    elTurrets.querySelectorAll('.turret').forEach(t=>{
      t.addEventListener('click', ()=> tap(Number(t.dataset.i)));
    });
  }

  function step(dt){
    if(over || !zombies.length) return;
    const speed = content.speed * (1 + wave * 0.08);
    zombies.forEach(z=>{
      if(!z.live) return;
      z.pos += dt * 0.00004 * speed;
      if(z.pos >= 1 && !z.breached){
        z.breached = true; z.live = false;
        wallHp--; elWall.textContent = wallHp;
        reportAttempt({ point:'通分', ok:false, ms: dt });
        field.classList.add('fx-crack');
        if(wallHp <= 0) return end('lose');
      }
    });
    paint();
  }

  function tap(i){
    if(over) return;
    const f = front();
    if(!f) return;
    const opt = f.opts[i];
    reportAttempt({ point:'通分', ok: opt.ok, ms: 0 });
    if(opt.ok){
      f.live = false;
      field.classList.add('fx-boom');
      if(!zombies.some(z=> z.live)){
        wave++;
        if(wave >= content.waves.length) return end('win');
        spawnWave();
      } else paint();
    } else {
      f.pos = Math.min(0.99, f.pos + 0.22);
      paint();
    }
    setTimeout(()=> field.classList.remove('fx-boom','fx-crack'), 220);
  }

  function end(outcome){
    over = true;
    cancelAnimationFrame(raf);
    finishRun({ outcome, ms: 0, wave, wallHp });
    showResult(outcome, { maxCombo: 0, hits: wave, total: content.waves.length });
  }

  function loop(now){
    const dt = last ? now - last : 16; last = now;
    step(dt);
    if(!over) raf = requestAnimationFrame(loop);
  }

  spawnWave();
  if(!SELFTEST_MODE) raf = requestAnimationFrame(loop);

  return { destroy(){ over = true; cancelAnimationFrame(raf); }, _step(dt){ step(dt); }, _tap(i){ tap(i); } };
}

function openGamePage(gameId){
  state.pageId = gameId;              // 与 state.gameId（容器里正在玩的）区分开
  renderGamePage(gameId);
  showScreen('gamePage');
}

function chainOf(game){
  const arr = [game];
  let cur = game;
  while(cur.parentId){
    const p = PUBLISHED.find(w=> w.id === cur.parentId);
    if(!p) break;
    arr.unshift(p); cur = p;
  }
  return arr;
}

function renderGamePage(gameId){
  const g = PUBLISHED.find(w=> w.id === gameId) || GAMES_INDEX[gameId];
  if(!g){ toast('这件作品不见了'); return; }
  const chain = chainOf(g);
  const m = MECHANICS.find(x=> x.id === g.mechanic);
  const board = [
    { name:'阿力', score: g.score + 400 },
    { name:'我',   score: g.score, me:true },
    { name:'小满', score: Math.max(0, g.score - 900) },
  ].sort((a,b)=> b.score - a.score);
  const h = document.querySelector('[data-screen="gamePage"]');
  h.innerHTML = `
    <header class="scr-head with-back">
      <button class="back" data-back="square">‹</button>
      <h1 class="gp-title">${g.title}</h1>
      <p>${g.author} · ${g.subject} · ${m.name}机制</p>
    </header>
    <button class="gp-play" data-play="${g.id}">▶ 立刻玩一局</button>

      <h2>二创树</h2>
      <div class="gp-chain">
        ${chain.map((c,i)=>`
          <span class="chain-node ${c.id === g.id ? 'cur' : ''}">

          </span>`).join('')}
      </div>
      <p class="gp-chain-note">${g.parentId ? '改自上一件作品 · ' : ''}衍生 ${g.remixes} 版 · 血缘不断，署名不改</p>

function publishCurrent(){
  const id = state.gameId;
  const src = GAMES_INDEX[id] || PUBLISHED.find(w=> w.id === id);
  if(!src){ toast('没有可发布的作品'); return; }
  if(PUBLISHED.some(w=> w.id === id)){ toast('已经发布过了'); return; }
  PUBLISHED.unshift({
    id, title: src.title, author:'我', subject: src.subject,
    mechanic: src.mechanic, plays:1, emoji: src.emoji,
    cover: src.cover || ['#2E1E5A','#7C5CFF'],
    parentId:null, remixes:0, score: 5200 + BUS.attempts.filter(a=>a.ok).length * 320, mine:true,
  });
  toast('已发布到广场');
}

function doRemix(gameId, tier, payload){
  const parent = PUBLISHED.find(w=> w.id === gameId);
  if(!parent) return;
  const mech = tier === 'mechanic' ? MECHANICS.find(m=> m.id === payload) : MECHANICS.find(m=> m.id === parent.mechanic);
  const title = tier === 'skin'  ? `${payload}版${parent.title}`
              : tier === 'material' ? `${parent.title}·${payload}版`
              : `${mech.name}版${parent.title}`;
  const id = 'w-remix-' + (PUBLISHED.filter(w=> w.id.startsWith('w-remix-')).length + 1);
  PUBLISHED.unshift({
    id, title, author:'我', subject: tier === 'material' ? payload : parent.subject,
    mechanic: mech.id, plays:0, emoji: parent.emoji,
    cover: tier === 'skin' ? ['#1E2E5A','#5A8AFF'] : parent.cover,
    parentId: parent.id, remixes:0, score:0, mine:true,
  });
  parent.remixes++;
  document.querySelector('.remix-sheet')?.remove();
  toast(tier === 'skin' ? '换好皮了，已放进广场' : '改好了，已放进广场');
}
