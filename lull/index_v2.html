② 卡片行为 · 语境生成

1

她每句话播报完 → 弹卡

3–4 个共情式选项由 LLM 根据当前语境实时生成——"嗯，我在听" / "然后呢" / "这确实挺难的" / "换我说给你听"，不是固定模板。

2

点选或输入 → 卡片收回，她继续

选项之外的意思，用输入框自由表达；发送后与语音输入同等对待。

3

连续忽略 3 张卡片 → 自动转回纯语音等待

不重复打扰——用户可能已经睡着了，或者只是想安静地听。

record_voice_over 模式切换 · 说出来就行

② 生成流程 · 三步

1

入口可选

首次使用时可选进入，跳过不影响任何功能；之后随时从设置发起。

2

几句自然语言 → 画像

不填表单、不选标签——用"她像深夜电台主播，温柔但有点丧"这样的人话描述。

3

微调直至合意

更暖 / 更清冷 / 重新生成；画像作为对话时的屏幕主体（呼吸微动的动态插画）。

palette 生成约束
  • · 插画风格而非真实人像——规避恐怖谷与肖像伦理风险
