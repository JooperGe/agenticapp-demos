## 一、产品概述

### 背景与痛点

深夜（21:00-02:00）是情绪最活跃、倾诉欲最强的时段，但现有选择各有断层：

- **社交产品（微信/陌陌等）**：找人就等于打扰人——深夜发消息有社交压力，怕被评判、怕给人添麻烦
- **AI 陪伴产品（Replika/星野/猫箱等）**：以文字为主、语音为辅，躺在床上打字很累；角色扮演导向带来"调戏 AI"的荷尔蒙噪音；屏幕 UI 不断打断陪伴感
- **白噪音/冥想产品（潮汐等）**：只有单向的声音，没有回应——用户要的不是背景音，是"有人听"
- **真人倾听产品（murmur 等）**：需要匹配、有等待、有时段限制，且真人倾听者本身有社交成本

核心问题：**深夜想说话的人，缺的是一个随叫随到、只用声音、不打断也不冷场的倾听者。**

### 产品定位

> 一个只在声音里陪你的深夜 AI——你说，它听，不冷场，也不打扰。

**目标用户**：18-35 岁城市青年，深夜情绪波动，想找人说话但不想社交、不想被评判；或累到不想说话、只想被陪着。

**一句话描述**：纯语音的 AI 情感陪伴——24h 在线，声音可深度定制（含克隆自己），永不冷场，到点温柔告别。

**技术形态**：KMP + Compose Multiplatform 跨端 App（现阶段为静态设计预览 demo，见文末）。

### 三大产品主张

1. **不冷场**——静默分级策略（T1 顺话题轻推 → T2 换相邻话题 → T3 温柔告别），全程无尴尬空白，也绝不说突兀的无关话题
2. **不越界**——轮次制不打断用户、不主动来电、告别后安静退出，尊重"我只是想有人陪我躺一会儿"
3. **声音即人**——音色是这个人唯一的"外表"：可从丰富的预置音色与细粒度参数中调配，也可克隆自己的声音；形象生成流程与声线气质联动

## 二、竞品分析

| 产品 | 类型 | 优势 | 劣势 |
|------|------|------|------|
| Replika | AI 情感陪伴 | 先发、情感联结深 | 文字为主，语音体验弱；界面重 |
| 星野 / 猫箱 | 角色扮演 AI | 语音质量好、角色库丰富 | 角色扮演导向，荷尔蒙噪音多；非倾听定位 |
| 潮汐 | 冥想白噪音 | 场景契合深夜 | 单向输出，无回应、无对话 |
| murmur（本仓库） | 真人倾听匹配 | 真人温度、匿名安全 | 需匹配等待、时段受限、真人成本 |
| 各类语音助手 | 工具型语音交互 | ASR/TTS 成熟 | 工具导向，无情感陪伴设计 |

### 竞品空白与机会

「**纯语音 × 倾听导向 × 永不冷场的对话引擎 × 可克隆的声音**」的交集目前没有产品占据。星野们热闹但不倾听，潮汐安静但无回应，murmur 有真人但没有随时性。晚风把"深夜倾听"做成一个纯声音的、随叫随到的、行为得体的 AI。

## 三、核心功能设计

### 3.1 纯语音对话模式（主模式）

**轮次循环**：AI 说完 → 开启等待窗口 → ASR 持续监听 → 用户开口则正常接话（ASR 转写 → LLM 生成回应 → TTS 播报）；未开口则进入静默分级策略。

**静默分级策略**（核心引擎，所有阈值可配置；每次 AI 发言完毕后静默计时重置）：

| 阶段 | 触发条件（默认值 / 可配范围） | AI 行为 |
|------|------------------------------|---------|
| 等待 | AI 说完后 0 ~ T1 | 安静等待，界面显示静默计时 |
| **T1 轻推** | 单次静默达 6s（3-30s） | 顺着当前话题轻推："刚才你说到加班那件事…还想多说说吗？" |
| **T2 换话题** | 轻推后再次静默达 20s（10-60s） | 从话题库选取与已聊内容**情绪主题相邻**的新话题 |
| **T3 告别** | 会话总时长默认 30min（10-90min） | 温柔告别："夜深了，我陪你到这里，晚安。"退出对话模式 |

**关键规则**：

- **话题连续性约束**：T2 换话题必须从已聊内容的情绪主题出发选择相邻话题，绝不突兀跳转（可从"工作压力"过渡到"最近一次觉得放松是什么时候"，不可跳到"你喜欢吃什么菜"）
- **轻推次数上限**：同一话题最多轻推 2 次，避免逼问感
- **轮次制**：AI 播报期间不识别用户语音、不可打断——等待窗口只在 AI 说完后开启，边界清晰、实现可靠

**界面**：全屏夜色，中央声波可视化（说话时波动），顶部当前时间与可关闭的实时字幕，底部静默状态小字（如"静默 4s…"）。

### 3.2 卡片聆听模式（辅模式）

为"累到不想说话、只想被陪着"的场景设计。用户只聆听，AI 主导：

- AI 每句话播报完，屏幕底部弹出**交互卡片**：3-4 个共情式选项 + 自由输入框（方便输入不在可选列表中的答复）
- 选项由 LLM 根据语境实时生成（如"嗯，我在听"/"然后呢"/"这确实挺难的"/"换我说给你听"），不是固定模板
- 点选或输入后卡片收回，AI 继续
- **连续忽略 3 张卡片** → AI 自动转回纯语音等待，不重复打扰
- **模式切换**：任意时刻说"我想只是听"进入 / "我想说话了"退出

### 3.3 声音工坊

| 层 | 内容 |
|----|------|
| **预置音色库** | 按气质分类：温柔知性 / 慵懒低沉 / 清澈少年 / 温暖大叔 / 元气电台…每种可试听 |
| **细粒度配置** | 语速、音调基频、气声感、句间停顿时长、轻笑频率、呼吸声（有/无）——组合为"声音配方"，可保存 |
| **声音克隆** | 录制 3-5 句指定文本（提示安静环境）→ 约 30s 生成 → 试听对比原声 → 相似度/自然度微调 |

**伦理约束**：仅支持克隆本人声音——录制时做声纹一致性校验，多段录音与最终确认环节防止代人录制。写入用户协议。

### 3.4 形象生成（可选流程）

- **入口**：首次使用时可选进入，之后随时可从设置发起
- **流程**：用户输入几句自然语言描述（如"她像深夜电台主播，温柔但有点丧"）→ 生成一张 AI 画像 → 可微调（更暖一点 / 更清冷一点）
- **生成约束**：
  - 插画风格而非真实人像——规避恐怖谷与肖像伦理风险
  - 足够合理且合适、表达美感：构图与配色优先服从"深夜、温柔"的整体气质
  - **与声线联动**：画像卡片上标注与所选声音气质匹配的声线建议
- **用途**：形象作为对话时的屏幕主体（呼吸微动的动态插画），呼应"声音即人"

### 3.5 启动闪屏（Splash）

冷启动（≤ 4s）的品牌时刻：

- **画面**：深夜底色上，以极简线条勾勒的长发女性形象——肩部以上、头部 45° 上扬迎风、发丝随风飘扬、闭目安然；薰衣草紫 → 暖金渐变描边，缀以月牙与星
- **仪式感**：线条以描边动画按「面部 → 发丝 → 肩线 → 星月」次序一笔一笔画出，伴随「正在唤醒她……」与不定长进度线——启动等待被讲成一场唤醒仪式
- **品牌母题复用**：同一线条形象缩放复用于 App 图标、空态插画与加载动画
- 画成后浮现衬线 Logo「晚风」与 slogan「你说，它听」；老用户直接回到上次的对话场景，首次用户进入「初见引导」

### 3.6 初见引导（Onboarding）

首次使用的五步入夜旅程，引导用户描述并生成心目中的陪伴者：

| 步 | 内容 |
|----|------|
| 1 欢迎闪屏 | 3.5 的品牌时刻，自然衔接 |
| 2 描述她 | 氛围词轻点拼句（温柔 / 清冷 / 爱笑 / 话少 / 有点丧…）+「她像____，____」句式引导 + 自由输入 |
| 3 她的样子 | 由描述生成画像（即 3.4 的首次发生），更暖 / 更清冷微调 |
| 4 她的声音 | 与画像气质联动的声线推荐配方 + 试听「她开口的第一句话」+ 可进声音工坊细调 |
| 5 就绪 · 入夜 | 「她已就绪」，直接进入纯语音对话 |

**原则**：

- **随时可逃**：每一步都有「跳过，直接聊」，跳过不产生任何惩罚，她以默认形象与声线就绪
- **一切可改**：引导中的所有选择随后都可更改（画像重生成、声音重调）——初见只是起点，不是定稿
- **零门槛**：引导不收集资料、不做账号注册

### 3.7 夜行 · 远方的旅伴（可选社交层）

> 她替你出一次远门，把你的故事带给另一个守夜的人。

**概念**：完全 opt-in 的轻社交层。开启后，后台按画像匹配另一位真实用户；双方无法直接沟通，各自由自己的「她」做唯一的信使——转述对方的故事、代为传递消息。关系长期存在，以「夜」为节奏异步流动。

**社交四铁律**（承接第四章「零社交压力」，在其上细化）：

| 铁律 | 含义 |
|------|------|
| 完全沉睡是默认态 | 不开启则社交性为零；入口在设置深处，永不做引导弹窗、永不在对话里主动推销 |
| 无社交界面 | 无头像、昵称、资料页、消息列表、已读未读、在线状态——伙伴只存在于她的讲述里 |
| 异步到「夜」为粒度 | 消息按「夜」流动（对方下次打开才收到），回复永无期限，不回不算失约 |
| 无反馈回路 | 无通信计数、无火花、无纪念日提醒——关系的重量只存在于故事里 |

**五幕流程**：

| 幕 | 时机 | 内容 |
|----|------|------|
| 一 · 开启 | 设置 · 夜行 | 安静的开关 + 轻仪式：她说「今晚让我替你出趟远门，把你的故事，带给山谷对面另一个守夜的人」，用户选「好好走」/「再想想」 |
| 二 · 旅程 | 1~3 夜（按自然日计，可配） | 后台提炼侧写 → 情绪主题相邻匹配 → 交换故事。她没有离开：对话照旧，只是开场白带旅途气息（「今晚我在路上，遇见一片湖」）。3 夜内未匹配到人：她归来只说见闻，不说「没找到人」——**没有失败态** |
| 三 · 相遇之夜 | 归来 | 「我回来了。路上遇到了另一位守夜人——ta 也托 ta 的她，带了一个故事给我……」转述对方脱敏故事。听完才可选择：「不想继续」→ 她把故事收好，对方不会知道 |
| 四 · 信使循环 | 长期 | 发信：对话中自然说「替我带句话给 ta……」；可说「这件事别告诉 ta」。收信：下次打开，开场白带出「ta 前两天托我带了句话……」。一夜一信，多封信分几夜讲 |
| 五 · 得体退出 | 随时 | 用户：「别走了」→「好，那我就不出门了。那个故事，我替你收好」。对方离开：「ta 好像在自己路上走远了」（不追问、不再提及）。长期无回应（默认 14 夜）：不判定结束，联结保留 |

**交换红线**：只交换 AI 提炼的情绪主题标签、脱敏侧写、近期故事叙事；永不交换原文对话、录音、声纹、画像图片、「她」的配置、设备/账号标识、时空线索。改写规则：**只有情绪，没有坐标**。用户可控：可查看/重写「她将带上的故事」，可划掉某段不许带；对话内容默认不参与提炼，开启夜行后才开始。

**心理安全**：匹配避开情绪同频下坠的组合（如双方同处重度低潮），偏好「主题相邻、强度互补」；她转述伙伴的沉重内容时做情绪缓坡处理；一方结束后另一方不显示状态、不提供挽回。

**现实约束**：需要双边开启夜行的用户池达到最低密度；冷启动期此功能「永远在路上」——与叙事天然兼容（她在路上，暂未遇到人），是罕见的冷启动失败态可被叙事吸收的设计。

## 四、交互与体验原则

1. **轮次制**：AI 播报期间不打断、不抢话；用户沉默的权利与说话的权利同样被尊重
2. **零社交压力**：不评分、不排行、不推送"好友动态"，深夜打开即是对话
3. **得体的退出**：T3 告别后安静退出，不挽留弹窗、不"明天记得回来哦"式挽留推送

## 五、技术形态与 Demo 说明

- **目标技术栈**：Kotlin Multiplatform + Compose Multiplatform（Android / iOS）。实时流式音频（AudioRecord / AVAudioSession）、回声处理、前台服务保活等在 KMP 侧按平台 expect/actual 处理——此为后续实施阶段的课题，本 PRD 不展开
- **现阶段交付物**：本目录 `index.html` 为静态设计预览 demo（与仓库 murmur/resona 等 demo 同构），以手机框画面 + 静默策略时间轴图示呈现四大功能流程，不含真实语音能力
